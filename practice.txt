# 練習リストの設定
#
# 列: 出力名  対象リスト(カンマ区切り)  基準精度  中央ラベル  判定元(scoresaber|beatleader)
#
# 自分の記録と突き合わせて、基準精度に「届いていない」譜面だけを集める。
#   - 未プレイの譜面は対象に含まれる（取りこぼし防止）
#   - 同じ曲に複数難易度があるときは、基準以下の難易度だけを残す
#   - 基準を超えた譜面は次回の生成時に自動で消える
# 判定元を省略すると scoresaber になる。
# カバーは ScoreSaber判定=シアン、BeatLeader判定=ピンク。
