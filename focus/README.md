# focus/ — 重点練習の候補リスト

bs-analysis の分析で選んだ「重点練習」の候補を置く場所。

- ここに置いた `.bplist` は、`practice.txt` の対象リスト名として使える（拡張子なしのファイル名で指定）。
- 練習リストと同じく、自分の記録が基準精度を超えた譜面は、次の更新で自動的に外れる。
- `playlists/` は自動掃除（sweep_orphans）の対象なので、候補ファイルはこちらに分けて置く。
- 候補の中身を入れ替えるときは、このフォルダのファイルを差し替える（`practice.txt` はそのままでよい）。

| ファイル | 選び方 | 作成 |
|---|---|---|
| `focus_ss03_crossover.bplist` | ScoreSaber★3で96%未満のうち、ノーツ密度2.0〜3.0/秒かつ手が中央を越える配置が10%以上（36曲38譜面） | 2026-11-25 暫定分析 |
| `focus_recommend.bplist` | ScoreSaber★0〜5からClaudeが選んだ推薦（39曲40譜面）。★0-2：遅い譜面で弱点の配置（下段の切り上げ・中央越え）／★3：速い切り返しが多い譜面（重点リストと重複なし）、両手同時に外向きへ横切りする配置（平行外側切り）を含む譜面／★4：フルコン済みで93%まであと少し、またはミス1以下でフルコン目前／★5：ミス1〜2で90%目前。基準は難易度ごとの `_thr` | 2026-11-25 |

基準精度：`practice.txt` で基準を `auto` にすると、難易度ごとの `_thr` を基準にする（★の違う譜面を1つのリストに混ぜるため）。

難易度ごとに書ける追加キー（出力時に `_` で始まるキーは取り除く）：
- `_thr`：基準精度（%）。これ以下なら残る
- `_site`：判定に使う記録（`scoresaber` / `beatleader`）。JBSL の譜面はランク外で ScoreSaber の精度が出ないので `beatleader` にする（JBSL の表示精度と一致することを確認済み）
- `_until`：期限（JST、`YYYY-MM-DDTHH:MM`）。過ぎたら出さない。JBSL の大会終了日時に使う

アイコン：focus/ の候補ファイルに `imageString` があれば、練習リストはそのアイコンを加工せずに使う（通常の練習リストは元リストのカバーを色変えして使う）。
